# Practice incident report

## Observed impact

What failed, for whom, and during what period? Separate observed impact from
possible impact. Use synthetic identifiers and omit secrets.

## Timeline

Record the observation, hypotheses, experiments, remediation, and recovery check.
Use timestamps or ordered steps; distinguish database state from external effects.

## Root cause and contributing conditions

Explain the mechanism with evidence. Which assumption was false? Why did existing
tests or signals not reveal it earlier? Avoid blaming individuals.

## Resolution

What changed and why did that address the mechanism? Include the regression test
and the exact verification result.

## Follow-up

List a small number of specific improvements, an owner or yourself, and an
observable completion condition. State remaining uncertainty.
